# OVNTA WELLNESS shop

Run: `python3 -m http.server 8000` in this folder, then open http://localhost:8000
(ya kisi bhi static hosting par upload kar do: Netlify / Vercel / GitHub Pages).

- Products, prices, coupons: `js/data.js`
- Real online payment: `js/data.js` mein `RAZORPAY_KEY` daalo. Khali = demo payment.
- Colours (Blinkit green #0C831F): `css/style.css` ke `:root` mein.
